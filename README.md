# 🍰 Delícias da Cris

Site profissional e responsivo desenvolvido para a confeitaria **Delícias da Cris**.

O projeto apresenta os produtos da confeitaria de forma organizada, moderna e acessível, permitindo que os clientes consultem valores e façam pedidos diretamente pelo WhatsApp.

## 📸 Sobre o projeto

O site foi desenvolvido para divulgar os produtos e serviços da confeitaria Delícias da Cris.

O catálogo está dividido nas seguintes categorias:

* Bolos
* Salgados
* Doces
* Festa na caixa
* Cestas de café da manhã

Cada produto possui uma imagem, uma breve descrição e um botão para consultar o valor diretamente pelo WhatsApp.

## ✨ Funcionalidades

* Layout profissional e responsivo
* Compatibilidade com computadores, tablets e celulares
* Menu mobile animado
* Catálogo separado por categorias
* Botões de contato pelo WhatsApp
* Link direto para o Instagram
* Galeria de produtos em formato de carrossel
* Animações durante a navegação
* Botão para voltar ao topo
* Destaque automático da seção atual no menu
* Imagens com efeito de zoom
* Rolagem suave entre as seções

## 🚀 Como executar o projeto

### Opção 1 — Abrindo diretamente

Baixe os arquivos e abra o arquivo:

```txt
index.html
```

### Opção 2 — Usando o Live Server

1. Abra o projeto no Visual Studio Code.
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html`.
4. Selecione **Open with Live Server**.

## 📥 Como clonar o projeto

```bash
git clone https://github.com/WhiteHD7/Delicias-da-cris.git
```

Depois entre na pasta:

```bash

```
